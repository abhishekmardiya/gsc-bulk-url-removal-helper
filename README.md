# GSC Bulk URL Removal Helper

[GitHub](https://github.com/abhishekmardiya/gsc-bulk-url-removal-helper)

Generate automation scripts for bulk URL removals in Google Search Console.

## Usage

1. Open `index.html` in a browser.
2. Paste URLs (one per line) or import from CSV.
3. Choose removal type: **Remove this URL only** or **Remove all URLs with this prefix**.
4. Click **Generate Automation Script** and copy the output.
5. In GSC, go to **Removals** → open DevTools (F12) → paste the script in the console → Enter.

Keep the GSC tab active while the script runs.
